# Banafsaj UI (React + Vite)

```bash
npm install
npm run dev      # development
npm run build    # production build in dist/
```

- `src/data.js`      — AR/EN translations and the ready-made designs list
- `src/App.jsx`      — page shell and home sections
- `src/Accordion.jsx`— the React accordion used on the site and in the designer
- `src/Playground.jsx`, `src/StartPage.jsx` — playground and "Start now" page
- `src/styles.css`, `src/dcss.css` — site styles and the copyable component CSS
